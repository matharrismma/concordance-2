What it will not do

  • It does not generate answers.

    It verifies a claim you bring, eliminating what is not the answer. The trail is the reasoning, and "generated": false is in every response.

  • It cannot be talked into a pass.

    Tolerances are clamped: a caller may tighten a check, never loosen it. No prompt reaches a verifier, because there is no model to prompt.

  • It does not keep your data.

    Claim text is de-identified before anything is sealed, and receipts carry no personal context.

  • It says so when it cannot check.

    An unverifiable claim comes back unchecked with a reason. A miss stays a miss — it will not bluff the rest.

Rate limits keep the door open for everyone. If your agent needs volume, run the engine yourself — it is stdlib-first Python and serves the same API offline, with no network and no dependence on us.

A conduit, not the source.
