The Floor

Every theory the sciences and mathematics actually run on, joined by what it rests on, what limits it, and what shares its form. One body, so you can walk from any theory to the ones holding it up. Drawn rather than listed, because a list cannot show you what is missing — you would have to already know.

The same floor, read the other way, is The Floor of Discovery — Scripture and the created order as one design. That page is for seeing it; this one is for walking it.

Where the floor is missing

A lattice, because a lattice has sites that can be empty. Eight dimensions down, the catalogue's sections across; each site asks what a section contributes to a dimension, and a dashed red cell is that question with nothing on the shelf to answer it. An empty site is a question, not automatically a gap — some combinations need not exist — but a whole row of them is a thin place worth walking to.
