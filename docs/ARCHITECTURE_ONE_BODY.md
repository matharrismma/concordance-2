# ONE BODY, MANY MEMBERS — no runtime agent swarm

Matt, 2026-08-26: *"Do we need multiple subagents?"* — asked of the coherent model that aims to need no
LLM. The answer is a load-bearing architecture commitment, fixed here alongside the O(1) commitment.

## The commitment

**The engine is one coherent deterministic whole with many differentiated members and one Head. It is
NOT a runtime multi-agent system.** Autonomous, coordinating agents are the one thing a coherent model
must not become, because they reintroduce exactly what the engine exists to remove.

Three reasons, each already ours:

1. **O(1), not O(n²).** The engine's authority is O(1) — one floor, no coordination overhead. A swarm
   of agents negotiating is O(n²) coordination — the counterfeit-consensus pattern ("fragile pretending
   to be permanent"). Adding agents is regressive against the thing that makes the engine strong.
2. **Coherence requires one structure.** A model is *coherent* because it rests on one verified keeping
   and one connective structure (the fascia). Independent agents can *disagree* — incoherence by
   construction, and a rebuilt hallucination surface with no deterministic arbiter.
3. **Determinism.** Every LLM agent added is non-determinism and an un-auditable authority. The goal is
   to shrink the neural surface toward zero, not spawn N copies of it.

The pattern is 1 Cor 12 (*etheto*, "God arranged the members"): many members, one body, one Head. A
coordinating agent-swarm is the Babel/Beast pattern — many voices, no head, O(n²), scatters. The
fascia is precisely what a swarm lacks: the single connective tissue that keeps the many members one.

## Where multiplicity DOES belong

- **Pure-function components** — the ~71 verifiers, the derivers, discern's routing. Many specialists,
  but they are *functions*: no autonomy, no LLM, no coordination, composable and auditable. This is the
  right "many."
- **Gathered voices** — the cloud of witnesses, denominational voices. Many perspectives, **concorded
  by the one engine**, never competing. Gathered, not coordinating.
- **Nodes** — many machines *run* the engine (the capacitor model); each is the *same* coherent engine;
  the centre stays small. Distribution, not a multi-agent system.

## The two honest exceptions

1. **Build time.** Fanning out subagents to parallelize *research* (measure many chiasms at once,
   adversarially verify a finding) is fine — a tool for *constructing* the engine, never part of the
   shipped engine.
2. **A surface translator**, if ever added: **one** small, authority-less translator is cleaner than
   several. Specialize by *routing to a deterministic component*, not by spawning a model per task; the
   verifier catches a bad translation because the truth lives in the keeping, not the model.

## The rule, in one line

Grow the **members** (verifiers, derivers, structural understanding), the **voices** (the corpus), and
the **nodes** — never a runtime swarm of agents. One body, one Head, O(1).
