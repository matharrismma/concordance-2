# docs/archive — the historical journals

What lives here: the dated journals, reviews, plans, punchlists, handoffs and the lessons register that recorded how the project was built — moved out of `docs/` on 2026-10-16 (issue #19) so that the top level holds only the documents that describe the system as it runs now. They are kept, not deleted, because the code cites them for provenance (`candidates.py`, `warrant.py`, `seals.py`, `factfind.py`, `cas.py`, `si_units.py`, the ark scripts, `eval/live_probes.jsonl` and their tests all point here) and because a decision's reasoning should stay readable. The rule: **an archived document is history, not a current claim.** Its counts, routes, page names and "open items" were true on the date in its header and are not maintained; where it disagrees with the running system, `GET /capabilities`, `GET /systems`, `docs/ARCHITECTURE.md`, `docs/WORLD.md` and `docs/REMAINING.md` are the authority. Relative links inside these files were written from `docs/` and may not resolve from here. Nothing is added to this directory except by the same kind of archive pass; nothing here is edited except to repoint a link.
