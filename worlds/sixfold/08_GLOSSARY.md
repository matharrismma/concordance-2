# 08 — Glossary

| Term | Meaning |
|---|---|
| **Accord, the** | The Aegis Accord: the multinational body that licenses capes. The establishment. |
| **Aegis-badged** | Registered and licensed. Also used as an insult: "a badge." |
| **Asking for quiet** | Submitting, by tap or verbal quit. |
| **Booth, the** | The commentary desk above the pit. |
| **Cape** | Any superpowered person, and also the literal garment hung on the post. |
| **Cape vs. Cape** | The sacred stipulation: the loser forfeits their identity forever. |
| **Crown Post** | Post 1, where the champion's cape always hangs. |
| **Down Count** | A ten count on a wrestler who can't stand. Replaces the ring-out count. |
| **Exit / exited** | Touched the floor, and lost. "She got exited." |
| **Floor, the** | Anything outside the rim. The DQ zone. |
| **Foundry, the** | SIXFOLD's home venue, a former Accord detention facility. |
| **Glass Night** | The Rotterdam catastrophe seven years ago that ended the Golden Run. |
| **Going loud** | Leaving the Hush, or using powers. In the Hex, an instant DQ. |
| **Golden Run, the** | The ~30-year era when capes were celebrities. |
| **Grounded** | A cape whose licence was revoked. |
| **Hex, the** | The six-sided pit. |
| **Hush, the** | The dampening field. Inside it, nobody has powers. |
| **Keeper of Posts** | The official who takes and hangs each cape at the rim. |
| **Ledge, the** | The tag alcove cut into one wall. |
| **Loud finish** | A double DQ: both wrestlers on the floor. |
| **Loud Rules** | A mythical no-Hush match. It does not exist. |
| **Rim, the** | The top of the six walls. Still inside. |
| **Rim judges** | Two officials who watch only for floor contact. |
| **Shadow** | A ride-along camera op assigned to one wrestler (see `06`). |
| **Six-Post** | A six-wrestler elimination match. |
| **Teeter** | Hanging over the outside of the wall without touching the floor. Still alive. |
| **The Hex doesn't care how you left** | The promotion's motto. |
| **Unregistered** | Capes who refused or lost their licence, and the rebel faction. |
| **Warden** | The referee. |
